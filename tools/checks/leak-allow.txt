# Allowlist for tools/checks/leak-scan.py: one python regex per line, tested
# with re.search against the matched text only (not the whole line). Keep each
# entry narrow: a marker word a real secret never contains, or a placeholder.

# Fake keys and tokens in tests carry a marker word: sk-or-v1-LEAKCHECK-...,
# sk-or-v1-FAKE..., sk-or-v1-PROBE-..., sk-or-SUPERSECRET-....
(LEAK|FAKE|[Ff]ake|PROBE|SUPERSECRET|EXAMPLE|[Ee]xample|PLACEHOLDER|DUMMY|[Dd]ummy)
# Counting fakes: 0123456789 / abcdefgh runs no generated key contains.
(0123456789|abcdefgh)

# Documentation tailnet addresses in tests and fixtures: the first /24 of the
# range (100.64.0.x), its last addresses (range-boundary tests), Tailscale's
# docs example 100.101.102.103, its MagicDNS resolver, and the router test's
# 100.100.1.2. Real tailnet nodes get random addresses; don't widen this.
^100\.64\.0\.[0-9]{1,3}$
^100\.127\.255\.25[45]$
^100\.101\.102\.103$
^100\.100\.100\.100$
^100\.100\.1\.2$

# Placeholder accounts in docs and CI: /home/user, /home/runner (GitHub
# Actions), /home/you, C:\Users\u, C:\Users\you, C:\Users\Public, CI runners.
^/home/(user|runner|you|me|USER|username|example|ubuntu|builder)$
(?i:[\\/]users[\\/]{1,2}(u|me|you|user|username|public|default|example|runneradmin|circleci))$
