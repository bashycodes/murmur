| D19 | Hands-free endpointing (2026-10-22) | Opt-in `SessionConfig.endpoint_silence_ms` (default `None` = off). | D22 | Release→text latency for long dictations (2026-10-23, `docs/proposals/streaming-asr-latency.md`; shells: `docs/proposals/streaming-asr-shell-api.md`) | Opt-in `SessionConfig.segment_pause_ms` (recommended 800; `segment_min_ms` 4000, `segment_soft_max_ms` 20000). The core's worker cuts the buffer at pauses with a streaming D16 VAD (cuts are a pure function of the audio), decodes each closed segment while the user keeps talking (priority over partials, which shrink to the open segment), and at commit decodes only the tail. It then joins the text and runs the guard, spoken cleanup, LLM and post-processing on the joined text. whisper gets the previous segments' last words as prompt. Engines that must not pre-upload (cloud, D18) opt out. It runs inside FlowCore, so flow-server, router fallback replay and the equivalence suite need no protocol change. Hands-free endpoint default 2000 → 1500 ms. Phase 0 also caps the partial window at 12 s, skips previews in trailing silence, and adds `wait_ms` / `route.client_ms`.
