# PROJECT_CONTEXT — Murmur (local-only dictation app)

Decisions: `docs/DECISIONS.md` (D1-D28). Versioning + releases: `docs/versioning.md`, `CHANGELOG.md`. Core API, architecture + "Changelog for shells": `docs/core-architecture.md`. Core requests from the shells: `docs/core-change-requests.md`. Model choices: `docs/model-benchmarks.md`.

Branch `integration` holds everything: `core`, `core-p1`, `parakeet`, `win-p1`, `android-int`, `android-p1`, the hybrid branches, `cloud-core`, `core-endpoint`, `win-cloud`, `android-cloud`, `router-route` and `server-fixes` (review fixes), and `crates-final`, `android-final`, `win-final` (the rest of the review) are merged into it.

**Review status:** `docs/reviews/2026-10-22-integration.md`. All P1/P2 findings are fixed on `integration` (core/router/server/client: S1-S11, S19, C3-C10, C17, C18; Windows (`win-final`): S2/S6, S4, S13, S14, S15, S17, S18, C8 hotkeys, C11-C14, P3 start-off-thread + mic error, P4 real-clipboard tests; Android (`android-final`): S1, S2, S4, S6 wording, S12, S16, S17, C1, C2, C15, C16, P3 consent banner / contentDescription placeholder / purge off Main / `jni_api.rs` exception + last error, P4 ManifestPrivacyTest; crates (`crates-final`): P3 keyless `custom` openai_compat on private hosts (both shells mirror the rule), P4 test gaps incl. build matrix `--target`). Still open, and why: **P3 budget** for unpriced custom providers and failed calls (needs a product decision: what a call costs when the provider has no price); **P3 Android TextMatching** "substring within ±500 chars" success rule (PLAUSIBLE; changing the V3 rule without device data risks duplicate inserts); **P3 Android accessibility-tree walks on Main** (up to 2 × 2 s, `MurmurAccessibilityService`; needs device timing to judge); **P5 refactors** (per-session core state, `Arc<ActiveSession>` in the router; churn only, their bugs are fixed) and the Kotlin URL parser staying a mirror of the router's (pinned by the shared `url_parse_vectors.json` fixture instead of an FFI call). Device-only confirmations: S16 background clipboard restore, S17 on-disk effect of secure_delete/VACUUM.

## Layout

```
crates/
  murmur-core/        lib: session engine, ASR/LLM seams, VAD, hallucination guard, spoken cleanup, deterministic post-processing, paste segments
  murmur-ffi/         C ABI (cdylib/staticlib, include/murmur_core.h) + JNI (feature `jni`)
  murmur-cli/         dev harness: `murmur-cli transcribe` (WAV → full pipeline), `murmur-cli clean` (LLM cleanup on text)
  murmur-llm/         llama.cpp cleanup engine as a cdylib plugin (libmurmur_llm.so / murmur_llm.dll), loaded at runtime (D10)
  murmur-asr-sherpa/  Parakeet-TDT ASR via the official sherpa-onnx crate (murmur-core feature `parakeet`, D12)
  murmur-protocol/    hybrid wire protocol v1 types + golden fixtures (D17; spec docs/protocol.md)
  murmur-router/      Router: the session API over local MurmurCore + injected remote backend; policy, buffer replay, circuit breaker (no network code)
  murmur-remote/      RemoteBackend: WebSocket client of murmur-server (the only client-side network code; feature `tls`)
  murmur-cloud/       opt-in third-party cloud STT (D18): CloudAsr/CloudBackend + 5 provider adapters over HTTPS (reqwest/rustls); linked only into cloud flavours
  murmur-server/      self-hosted server: unmodified MurmurCore per session, bearer auth, worker pool, systemd unit in dist/
  murmur-build-info/  product version + git commit baked at build time (D26; no deps)
  murmur-contract-tests/  equivalence (local vs server / mock cloud), toggle matrix, build matrix, TLS, key-leak
apps/
  murmur-windows/     Tauri 2 shell (own cargo workspace; MSVC cross-check shims in tools/check-shims)
  murmur-android/     Kotlin shell (Gradle; JNI contract JNI_CONTRACT.md, install guide INSTALL.md)
docs/               DECISIONS, core-architecture, core-change-requests, model-benchmarks, bench/
tools/              fetch-models.sh, build-android-parakeet.sh, check-version.sh + release.sh + versioning/ (D26), probes/
VERSION             the product version (single source, D26); CHANGELOG.md = release notes
```

## How to verify

* Core: `cargo test --workspace`. Full: `BINDGEN_EXTRA_CLANG_ARGS="-I/usr/lib/gcc/x86_64-linux-gnu/13/include" SHERPA_ONNX_LIB_DIR=<sherpa-onnx lib dir> cargo test --workspace --all-features` and `cargo clippy --workspace --all-targets --all-features -- -D warnings` (llama-cpp-sys-2 needs the BINDGEN flag even for the default build on this box). Real-model tests skip without `models/` (`tools/fetch-models.sh [--llm] [--parakeet]`).
* Hybrid (D17): `cargo test -p murmur-contract-tests` (+ `--all-features` with `MURMUR_MODELS_DIR`/`MURMUR_PARAKEET_DIR` for real-model equivalence); `tools/check-build-matrix.sh`; end-to-end smoke with a real server: `tools/probes/hybrid_smoke/run.sh` (PARAKEET_DIR, AUDIO_DIR).
* Cloud STT (D18): `cargo test -p murmur-cloud -p murmur-router -p murmur-contract-tests` (mock HTTP; no keys needed). Live provider smoke: `MURMUR_CLOUD_LIVE_<OPENROUTER|ELEVENLABS|GROQ|OPENAI|DEEPGRAM|ASSEMBLYAI>_KEY=… cargo test -p murmur-cloud --test live_smoke -- --nocapture` (skips without keys; costs money).
* Replay harness: `cargo test -p murmur-replay`, `python3 -I tools/replay/test_score.py`; real runs per `tools/replay/README.md` (models, memory rules, spend cap).
* Versioning (D26): `tools/check-version.sh` (also run by `tools/check-build-matrix.sh` and CI); `tools/release.sh X.Y.Z` = dry run.
* Windows shell: `cd apps/murmur-windows && cargo test` (293), plus the MSVC clippy cross-check in its README.
* Android shell: `cd apps/murmur-android && ANDROID_HOME=~/Android/Sdk ./gradlew testDebugUnitTest assembleDebug` (Gradle daemon on JDK 21): 405 JVM tests per flavour, 12 gated skips; native libs `tools/build-native.sh --flavor F` + `tools/probes/check_native_so.sh --flavor F <apk>`.
